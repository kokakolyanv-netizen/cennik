# Ценники

Генератор ценников для десертов. Работает в браузере, ставится как приложение на телефон, планшет и компьютер, печатает векторный PDF на A4 и A5. Сервер и сторонние библиотеки не нужны, после установки работает без интернета.

## Как устроено

| Файл | За что отвечает |
|---|---|
| `app/engine.js` | Движок без интерфейса: размеры шаблона `SPEC`, категории `CATS`, разбор шрифта, вёрстка `layout`, цвета `paint`, переливы `field` / `autoMesh` / `PRESETS`, углы `CORNERS`, разбор списка `parseList`, сопоставление с каталогом `mergeList`, КБЖУ, раскладка `sheets`, `pdf` |
| `app/app.js` | Интерфейс: список, редактор, редактор фона, углы, загрузка списком, настройки, перенос, установка |
| `app/index.html` | Разметка и стили |
| `app/font.js` | Встроенный шрифт (собирается `tools/make-font.js`) |
| `app/sw.js` | Работа без интернета |
| `tests/run.js` | Проверки движка |

**Каталог.** `S.tags` хранит все ценники, это и есть каталог. На листе те, у кого `qty > 0` (`onSheet()`). Загрузка списком сопоставляет названия через `mergeList`: новое добавляется, у известного обновляются только указанные поля.

## Запуск у себя

```
python -m http.server 8767 --directory app
node tests/run.js
```

## Как добавить функцию

- **Категория:** строка в `CATS` (`tier`: 0 питание, 1 особые, 2 вкус, 3 вид; `kw`: слова, `!слово` отменяет категорию).
- **Готовый перелив:** строка в `PRESETS`.
- **Форма углов:** запись в `CORNERS` и предел радиуса в `maxR`. На экране и в PDF появится сама.
- **Новое поле ценника:** поле в `editor()`, ключ в `calc()` (иначе ценник не перерисуется), вывод в `layout()`, перенос в `readState()`.
- **Новая настройка:** значение по умолчанию в `DEF`, старые данные приводит `tune()`, перенос в `readState()`.
- **Новый файл приложения:** добавьте в `FILES` и увеличьте `V` в `app/sw.js`.

Перед публикацией запустите `node tests/run.js` и увеличьте `VERSION` в `app/app.js`. После отправки в ветку `main` сайт обновляется сам, установленные приложения получают новую версию при следующем открытии с интернетом.

## Неизменные правила

Карточка 77×55 мм, отступ 5 мм со всех сторон, цена 48 pt, состав и КБЖУ 6 pt. Название подбирается само и переносится только по словам. Буквы по умолчанию белые. До 4 ценников A5, больше A4. PDF только векторный.
